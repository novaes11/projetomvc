Como o MVC Funciona Neste Projeto

Model: Representa as entidades do sistema (Livro, Autor, Categoria, Usuario, Emprestimo) e suas regras de negócio.

Controller: Recebe as requisições HTTP do navegador, manipula as listas em memória e direciona para as páginas corretas.

View: As telas HTML renderizadas via Thymeleaf que apresentam os formulários e tabelas para o usuário interagir.
